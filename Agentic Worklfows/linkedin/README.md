# LinkedIn

Lorenzo's LinkedIn outreach channel. He does every prospect-facing action on LinkedIn himself; Grok Bot's LinkedIn agent does the one-time profile setup and saved searches (PLAN.md, Phase 0); Claude drafts.

- `PLAN.md`: the phases (foundation, warm-up, Loom launch, verdict), who does what, and the decision on who sends connection requests.
- `outreach_copy.md`: every message text. Blank connection request, Loom scripts A (Reactivation) and B (Reply and booking / outbound), the DM per variant, FU1 to FU3, voice note, reply templates. Placeholders: {first_name}, {role}, {company}, {what_they_do}, {slot1}, {slot2}.
- `profile_kit.md`: headline, About, banner, services and the profile checklist.
- How to run the channel: the `linkedin-outreach` skill at `~/.claude/skills/linkedin-outreach/SKILL.md`.
- The SOP: `../directives/USER/linkedin_outreach.md`.
- Posts: the `linkedin-content` skill.
