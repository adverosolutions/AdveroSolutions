When asking Lorenzo to approve or pick copy (emails, texts, scripts) with a question dialog, put the full message exactly as the lead would see it inside the question itself (the option `preview`, or the question text), every time. Never ask "good to go?" about a message he can only see in chat above the dialog.

**Why:** 2026-09-23, section 2 walkthrough: he dismissed an approval question and said I was asking as if he knew exactly what I meant; he wants the message in front of him at the moment he decides so he can double-check it.

**How to apply:** one message per question; each option's preview shows the rendered message (sample values filled in) for that choice, with any proposed cut visible. Related: [[upwork-proposal-copy]], [[feedback-estimates-and-stopping]].


UPDATE 2026-10-06: in a multi-question dialog he could not see the option previews ("cant see them"). Put the full rendered message in the question text itself AND in the chat message right above the dialog; don't rely on previews alone.
