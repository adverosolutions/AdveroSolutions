# Advero Community Sales Playbook (from Lorenzo, pasted 2026-10-20 11:32 CT). This is THE community plan.
Google doc version: https://docs.google.com/document/d/1p7zJHGhKtc1QzBTiO51aWSQdIlgnmf7I4S0CimKJBgQ/edit
Niches: commercial cleaning, PPC agency owners, pest control owners. Start with 3 communities, one per niche (Skool or FB), active, owners asking business questions and getting useful replies. Maker School suggests ~100-1,000 member FB groups. Check entry/promotion/DM rules; be honest he builds automation; skip vendor-banned groups; paid optional.
Problems to validate (save owners' exact language): cleaning estimates/walkthroughs not converting; PPC client leads slow response/never book; pest control missed inquiries, unbooked estimates, lapsed customers.
Content: 15 posts across 3 communities over ~26 days (5 each), rotate niches. Structure problem -> practical steps -> screenshot/demo -> answer questions. Small working example with sample data. Lorenzo writes final posts; no pitch, no invented results. First demo: estimate follow-up board with next action + reminders that stop on reply (test before claiming).
Conversations: answer publicly; DM only with permission where rules allow; a like is not permission. Draft public reply and post-permission DM templates in the Google doc (rewrite per person). Qualify: what happens now, frequency, cost, decision-maker. Then offer walkthrough call; small paid project with scope/price/success measure (price never in writing by agents).
Daily: 5 min engagement per community + 5 min replies/tracker; posting days +30 min creation.
Tracker: name, community, conversation link, problem, DM permission, stage (conversation -> qualified problem -> call -> proposal -> client), next action/date. Friday review.
Maker School lessons Day 3-6 (join 3, post calendar, first post, 5-min engagement).
Agent rules: joins + engagement drafts by Community Manager; membership answers, posts, comments, DMs all ask-first via hold card to Lorenzo.
