# Cold Email Copywriting

A fixed system for writing cold emails so every draft follows the same proven shape instead of being reinvented from scratch each time.

## Core Philosophy (always apply)

Every email in this skill is built on Alex Hormozi's principles from *$100M Offers* and *$100M Leads*:

- **The Value Equation**: Value = (Dream Outcome × Perceived Likelihood) ÷ (Time Delay × Effort/Sacrifice). Every line either raises the top or shrinks the bottom.
- **Give before you ask**: the free resource/insight/value always comes before any request for time.
- **Specificity = believability**: no vague claims ("I help businesses grow") — always a number, name, or concrete detail.
- **Low-friction CTA**: never ask for a call as the first ask. Ask a yes/no question or "want me to send it?"

## The Universal 4-Part Skeleton

Every cold email follows this exact order — do not deviate:

1. **Subject Line** — curiosity/relevance, 3–6 words, never salesy
2. **The Opening (Hook)** — one sentence proving specific homework, zero pitch
3. **The Value** — a specific solution or free resource, offered before any ask
4. **Low-Friction CTA** — a small, easy yes (not a calendar link as the first ask)

Keep total length under ~120 words. Tone is friendly, peer-to-peer — like a friend or student working on a project, not a sales rep. No "I hope this email finds you well," no "circling back," no corporate throat-clearing.

## Choosing an Angle

Ask the user (or infer from context) which angle fits, then load the matching reference file for the full template, variable list, and worked example:

Read only the reference file(s) needed for the current request.

## Variables to Fill

Every template uses placeholder variables (Instantly-style merge tags), e.g. `{{firstName}}`, `{{companyName}}`, `{{icebreaker}}`, `{{painPoint}}`, `{{leadMagnet}}`, `{{proofPoint}}`, `{{cta}}`. If the user hasn't given specifics (their offer, the lead's info), ask for what's missing or use sensible bracketed placeholders the user can swap in later — never silently invent fake company names, results, or proof points and present them as real.

## Workflow

1. Identify the angle (ask if ambiguous, or ask which of the four fits).
2. Read the matching reference file(s) in `references/`.
3. Fill the template with the user's actual offer/lead details, or leave clearly-marked placeholders if info is missing.
4. Run the output against the tone checklist in the reference file before delivering.
5. If the user wants multiple angles compared, produce one email per angle, clearly labeled.
