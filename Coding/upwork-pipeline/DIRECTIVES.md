# Upwork standing directives and change log

This is the durable record of Lorenzo's instructions for Upwork demos and proposals. Every session must read the active directives before planning, authoring or reviewing. Current human instructions take precedence. Later instructions supersede earlier ones only within their stated scope.

## Automatic maintenance

Whenever Lorenzo gives a standing instruction or correction:

1. Record it here during the same turn, without asking whether to save it. Include the client date, scope, active/superseded status and implementation pointers.
2. Update the affected working rules, template or review checklist. Logging a directive without applying it is insufficient.
3. Retain superseded instructions as history and point to their replacement. Never silently erase them.
4. Apply active rules to every subsequent generation and relevant delegated brief. Check them before independent approval.
5. Keep job facts scoped to their job. A particular client's name, chosen tool, sample figures or one-minute Loom does not become a global default unless Lorenzo says so.
6. Refresh the master handbook export after rule updates. Preserve the shared Claude skills and global model settings.

This is a required step whenever an agent handles a new instruction in this pipeline, not a scheduled monitor or background reader of other chats. Read the active summary first; consult older history selectively. If history grows large, archive dated sections with links here, preserving the complete record.
