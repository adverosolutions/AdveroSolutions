This is a working prototype of NexGrowth's sales call review prompt.

1. Built around one goal: every call reviewed, about 65 manager hours a month back.
2. A call transcript goes in, a coaching card comes out.
3. The prompt: instructions, a weighted rubric, worked examples, the JSON schema.
4. Same JSON every time, rendered as the rep's coaching card.
5. Eight test cases; v1.2 invented an objection, v1.3 fixed it.
6. The compliance prompt quotes the risky claim and the missing disclosure.
7. Every prompt versioned, with what changed and why.
8. One line in Claude Code runs the tests and logs the change.
