Why it's built this way

Claude reasons, n8n acts.

The agent only reads and decides. Anything that changes the outside world goes through one n8n webhook, so it can be retried, paused or audited in one place.

 

Every tool is a typed API call.

Tools have strict inputs and read or write scopes. The agent cannot reach a system it was not given, and every call is replayable in tests.

 

Policy is a file, not a prompt.

Your rules live in versioned policy docs the agent must cite. Change a rule, rerun the evals, ship it.

02 · Work confidently with Claude Code

The agent is a small, readable Claude Code project.

One CLAUDE.md with the house rules, a subagent definition, one file per tool, the approval gate in code, policies as Markdown and recorded requests as evals. Open it in Claude Code and change it by asking.
