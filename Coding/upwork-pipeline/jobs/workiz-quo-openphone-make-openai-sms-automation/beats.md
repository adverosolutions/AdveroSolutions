# Loom beat sheet

- workiz assigns you the job, the customer gets a text automatically
- node two pulls customer, job type, address, time window
- openai writes the first sms from your own template
- quo sends it from your existing number, not a new one
- customer replies, agent picks a pre-approved template, never freestyles
- your rep approves or edits in slack before anything sends
- real risk: workiz webhooks and quo api access depend on your plan
