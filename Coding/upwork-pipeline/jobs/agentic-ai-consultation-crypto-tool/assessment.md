## Likelihood
- Brand new client account: 0 contracts, 0 feedback, 0 hires, 0 invites, posted today, already 45 to 50 bids and 7 connects to apply. High competition, unproven payer, and the fixed price will not clear escrow drama if they ghost.
- The real value here is not the $50, it is that this is a scoping call for four build tracks. Anyone who wins the hour is first in line for the build. Treat the fee as irrelevant and the positioning as the whole point.
- What breaks: they came in with "Python and TensorFlow" as the starting assumption and the most urgent item is the one Lorenzo should build last. If he validates TensorFlow to be agreeable he is worthless to them and it shows on the call. The honest answer is the differentiator.
- **Unverified experience, state it plainly:** anomaly detection with machine learning is outside Lorenzo's confirmed experience. Do not claim ML modelling in production. The honest position on the call and in the copy is: statistical rules first, measure catch rate against what your humans catch, then a scikit-learn model such as an isolation forest if the rules genuinely miss real cases, and he brings in a data scientist if a neural net is ever actually justified. TensorFlow at 40k rows is the wrong tool and saying so is the credibility.
- Everything else on their list is squarely his lane: support ticket deflection with Claude grounded in their docs, ID verification via an OCR and face-match vendor API rather than a trained model, marketing and email automation, lead lists, and spreadsheets to a real database on AWS. He runs 100k+ cold emails a month on his own infrastructure with an agent writing each message, which is the marketing and email answer already built.
- Be direct that most of their list is automation, not AI. They are paying for someone to tell them that. A consultant who says "yes, all four are AI" is selling them a year of work they do not need.
- Timezone Asia/Jerusalem, client in Ukraine: offer the call window explicitly so scheduling is not a round trip.

- A senior consultation of this kind is $150 to $400 for the hour. Specialist AI advisory retainers run $200 to $350/hr.
- If it converts to build work, reference ranges: ticket deflection $2.5k to $5k; ID verification integration $4k to $8k plus per-check vendor cost roughly $0.50 to $1.50; anomaly rules engine $3k to $6k; scikit-learn model on top $5k to $10k and only after the rules are measured; Excel to database plus lead and email automation $3k to $6k.
- Recurring software they should expect: AWS compute and storage, Anthropic API usage for tickets, an ID-verification vendor per check, an email sending platform.
- He bids the $50 as posted on purpose. The reference number above is for the call, not the proposal.

## Ask before quoting
- Anomaly detection: how many labelled examples of confirmed suspicious activity do you actually have, and how far back does the trade history go? No labels means unsupervised only, and that changes everything about the estimate.
- Are you using an identity-verification vendor today, or is it genuinely all by eye? If a vendor is already in the stack the ID work is a fraction of the estimate.
- Ticket volume and channel: how many a month, and do they arrive by email, a helpdesk, live chat or Telegram? Deflection numbers depend entirely on the channel.
- Which AWS services are already running - Lambda, ECS, RDS, S3, SageMaker? Whether there is already a database changes the Excel migration from weeks to days.
- The separate blockchain project: does it share the trade data model or is it isolated?
