How the Masterclass launch works
Team doc · updated with each launch
Each month
  1. Duplicate last month's funnel, form, tags and workflows, then rename to the new month.
  2. Set the countdown and page date to the new session.
  3. Create the Zoom meeting and point the Zap at it.
  4. Register a test contact and check every reminder lands.
  5. After the event, import the attendance report so the tags start the follow-up.
If something breaks

Check Zapier task history first, then the workflow's Execution Logs for the contact.
