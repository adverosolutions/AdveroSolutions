Why it's built this way

It fails loudly, never silently.

Every call has retries, the AI step has a fallback, and an error workflow tells you the moment anything breaks.

 

AI only where judgement is needed.

Plain rules handle cleaning and filtering. OpenAI is used for the one step that needs reading comprehension, with a strict output schema.

 

The next person can read it.

Numbered node names, a sticky note on every section and a version history, so a change never needs the person who built it.

02Integrate OpenAI and other AI APIs

OpenAI reads the message. Your rules decide.

The model returns structured JSON that is checked against a schema before anything downstream trusts it. If OpenAI is slow or down, Claude answers the same prompt.

Prompt, step 04

03Connect REST APIs and webhooks

      
In through a webhook. Out through REST.

      
The webhook checks a shared secret and answers in milliseconds, so the sender never waits on the AI. Outgoing calls retry with backoff and respect rate limits.

      09Clean, reliable, easy to manage
      
      
      Built to be handed over, not just built.
      
      
      You asked for workflows that are easy to manage rather than basic automations. These four habits are what make that true six months from now.
      
      
      
        
      
          Naming conventions
          
      Every node says what it does.
      
          
      Numbered in run order, verb first, app last.
      
          
      HTTP Request306 - Create contact in HubSpot
      
          
      IF103 - Drop spam and duplicates
      
          
      OpenAI04 - Classify and score with OpenAI
      
          
      My workflow 7 (copy)01 Lead intake
      
        
      
        
      
          Sticky-note docs
          
      The canvas explains itself.
      
          
      One note per section, written for the next person.
      
          
      ScoringOpenAI scores each lead from 0 to 100. Anything 70 or above goes to sales in Slack and becomes a HubSpot contact. To change the cut-off, edit the value in node 05. Claude answers if OpenAI times out.
