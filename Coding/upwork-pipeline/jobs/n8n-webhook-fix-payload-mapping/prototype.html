Hardening added

      

        
Input validationA new Code node before the mapping checks order_id, contact.email and at least one item. A payload missing any of them goes to the error branch with the reason, instead of crashing the mapping.

        
Defaults for missing fieldsNo last name gives the first name alone, no currency gives USD, no quantity gives 1, a date that won't parse gives the time received.

        
Types the API acceptsTotals, prices and quantities cast to numbers (commas and currency symbols stripped), dates to ISO 8601, email trimmed and lowercased.

        
Any payload shapeWorks whether the sender wraps the record in body.data or not, sends one item or a batch, and sends items as an array or a single object.
