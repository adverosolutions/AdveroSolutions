Why it's built this way

It runs on your paid Zapier, not Make.

Make's free plan allows two active scenarios and checks at most every 15 minutes, so this would use up half of it. Your Zapier plan already covers it, and you keep Make free as you asked.

Folders sort themselves by date.

The project date is written as 2026-10-17 at the front of every folder name, so pCloud lists your projects in shooting order without you renaming anything.

It is safe to run twice.

If a folder with that name already exists, the zap uses it instead of making a second one. A project with no date waits with a note instead of making a folder called "_Ava and Theo".

Couples, companies, dates and links in this prototype are made-up sample data. Timings are illustrative.

    Inside the automation

    Twelve steps, one zap, on your Zapier account.

    The trigger, the Formatter steps and the filter don't count toward your Zapier tasks, so each project uses about 8 tasks. The pCloud steps talk to pCloud's API directly through Webhooks by Zapier, which your paid plan includes.

      Naming rules · try your own
      Subfolder names
      • The date is written year, month, day, so folders sort in shooting order.
      • An ampersand becomes "and", because links and some apps break on "&".
      • Extra spaces are trimmed, and characters pCloud rejects, like / : * ? " < > |, are removed.
      • Your post names the subfolders two ways, so both are ready and you pick one.
      When something is off

      The folder already exists.

      The zap finds it and uses it, so you never get "Ava and Theo Linden (1)", and the links still fill in.

      The project date is missing.

      Your PCLOUD view only lets in records with a date, so the project waits with a note and runs the moment you add one.

      The client name is blank.

      The filter stops the run before pCloud is touched, and the record shows what to fill in.

      pCloud doesn't answer.

      Zapier retries the step, and if it still fails you get an email naming the project.
