# Screening answers (paste into the Upwork form)

1. How would you audit an existing set of GHL workflows to find problems before they affect leads?

I push one test lead through your intake/lead-routing workflow and note every workflow it enters. Then I line up the triggers on your 8 follow-ups against your older workflows to catch any two firing on the same event, check the waits against your discovery and in-home consult calendars, and look at every If/Else for a path where a lead drops out with nothing after it. For silent failures, each workflow adds an entry tag in its first step, so a lead with none shows up in a filter or in Claude's check, and an If/Else before each message holds anything with a blank merge field and creates a task to fill it.

2. Have you worked with Claude's MCP connector or the Anthropic API? How did you use it?

Yes. I run Claude through the Anthropic API in my own sales system, with Haiku for classification and Sonnet for drafts, and I connect Claude to GoHighLevel through the API and MCP in my own sub-account. I've also deployed Claude agents in my agency and for a number of client companies.
