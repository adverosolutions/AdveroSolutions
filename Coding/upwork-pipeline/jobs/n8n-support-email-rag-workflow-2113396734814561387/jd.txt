Project Overview

We’re looking for an experienced n8n AI Automation Specialist to build and document an AI-powered customer support email workflow for our internal agency operations.

The workflow should identify incoming support emails, retrieve relevant information from our knowledge base, generate appropriate AI-assisted responses, and reply through Gmail while preserving the original email thread.

We need a reliable, well-organized, and maintainable solution that our team can configure, test, and activate after handover.

Scope of Work

1. Workflow Development

Build an n8n workflow following this process:

Gmail → AI Classification → Knowledge Retrieval (RAG) → AI Response Generation → Gmail Reply

The workflow should:

- Monitor incoming emails through a Gmail trigger.
- Capture the sender, subject, email body, message ID, and thread ID.
- Classify incoming emails using an OpenAI model to identify customer support requests.
- Route non-support emails out of the workflow without generating unnecessary responses.
- Retrieve relevant information from an existing Pinecone knowledge base using OpenAI embeddings.
- Generate clear, professional, context-aware responses using an OpenAI model.
- Reply through Gmail while preserving the original email thread where supported.
- Include a simple human-escalation path when the knowledge base does not provide sufficient information.

2. Integrations & Reliability

Configure and validate the following integrations:

- n8n workflow and credentials
- Gmail / Google Workspace
- OpenAI API
- Pinecone vector database and existing knowledge index

Additional requirements:

- Implement basic error handling and retry logic where appropriate.
- Handle missing or insufficient knowledge gracefully.
- Avoid hard-coding API keys or credentials.
- Keep the workflow modular, readable, and easy to maintain.

Credentials and access to the required services will be provided by us.

3. Testing & Validation

Test the complete workflow against representative scenarios, including:

- Support and non-support emails
- Relevant and irrelevant knowledge-base results
- Appropriate AI response generation
- Missing or insufficient knowledge
- Gmail thread continuity
- Credential or integration failures
- End-to-end workflow execution

Provide a concise testing summary and validation checklist documenting the results.

4. Documentation & Handover

The final delivery must include:

1. Workflow Design & Integration Mapping – Explanation of the workflow nodes, integrations, and data flow.
2. Process Flow Diagram – Visual representation of the automation process.
3. Testing Notes & Validation Checklist – Scenarios tested, results, and known limitations.
4. Project Handover Summary – Setup instructions, credential configuration, activation steps, and maintenance notes.
5. Importable n8n Workflow JSON – The completed workflow, ready to import into our n8n environment.

Required Experience

- Hands-on experience building n8n automation workflows
- Practical experience with OpenAI APIs and LLM-powered automation
- Understanding of Retrieval-Augmented Generation (RAG), embeddings, and vector databases
- Experience integrating Gmail or Google Workspace APIs
- Familiarity with Pinecone
- Knowledge of API authentication, error handling, and workflow testing
- Ability to document and hand over a solution clearly

Definition of Done

The project will be considered complete when the workflow is delivered in importable JSON format, the agreed integrations and workflow paths are configured, representative test scenarios have been executed, and the documentation and handover materials are provided.

This is a one-time implementation project. We value clear communication, maintainable automation, proper testing, and a complete handover.
