Build an automated LinkedIn content scheduling system using n8n, Airtable, and Buffer. The project includes draft intake, an approval step, scheduling, safeguards against duplicate or bad posts, and post-publish tracking. Deliverables should include five connected n8n workflows, an Airtable base as the backend, Buffer integration for scheduling, and end-to-end testing and auditing. This is a fixed-price project for a first contract, test and review.
