# Installing the email signature

1. Host the logo first: upload `email-mark-128x128.png` to your website (or any public host) so it opens at a public https URL. Gmail and Outlook can't use a file from your computer.
2. Open `signature.html` in a text editor and replace `[LOGO URL]` with that https URL. Replace `[PHONE]`, `[WEBSITE URL]` and `[BOOKING URL]` with the real links, and `[Phone]`, `[Website]` and `[Book a call link]` with the text you want shown. Save.
3. Open `signature.html` in Chrome, press Cmd+A, then Cmd+C.
4. Gmail: Settings (gear) > See all settings > General > Signature > Create new, paste with Cmd+V, set it as the default for new emails and replies, then Save Changes at the bottom of the page.
5. Outlook on the web and new Outlook: Settings > Accounts > Signatures > New signature, paste, pick it as the default for new messages and replies, then Save.
6. Classic Outlook for Windows: File > Options > Mail > Signatures > New, paste into the edit box, choose the defaults, then OK.
7. Send yourself a test email and check it in both light and dark mode on your phone.
